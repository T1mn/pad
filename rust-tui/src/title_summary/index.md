# title_summary

- `../title_summary.rs` 内联 `types`：标题摘要请求结果、wire API 类型与默认模型常量。
- `../title_summary.rs` 内联 `window`：是否启用、刷新阈值与 turn 窗口选择。
- `../title_summary.rs` 内联 `normalize`：模型返回标题的前缀、包裹符与长度清理。
- `../title_summary.rs` 内联 `prompt`：标题摘要 prompt 构造。
- `request.rs`：Responses/Chat 请求发送与重试入口。
- `../title_summary.rs` 内联 `response`：Responses/Chat 响应和错误文本解析。
- `../title_summary.rs` 内联 `util`：日志截断等共享小工具。
- `tests.rs`：标题摘要窗口、wire API 与标题清理回归测试。
